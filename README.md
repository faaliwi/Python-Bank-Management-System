# 🏦 Bank Management System

A simple Bank Management System developed using Python.

This project was created to practice Python programming, GUI development, and database management.

## Features

- User Login

- Create Bank Accounts

- View Account Information

- Update User Profile

- Check Account Balance

- Transfer Money Between Accounts

- SQLite Database Integration

## Technologies

- Python

- Tkinter

- SQLite

## Project Structure

- `gui.py` - Graphical User Interface

- `Bank_DB.py` - Database operations

- `main_Bank.py` - Main program

## Purpose

This project is part of my Python learning journey and focuses on combining:

Python + GUI + Database

to build a complete desktop application.
